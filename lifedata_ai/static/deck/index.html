Where We Started

Before this sprint

A basic dashboard-editing chatbot

  • Embedded copilot panel — injected directly into Superset pages, not a separate chat app
  • Its own hand-built tool loop — custom read/write/ask_user tools, not Superset's native AI protocol
  • Chart & dashboard CRUD — create, edit and lay out charts and dashboards by request
  • Filters, beautification, themes — basic styling and dashboard-level controls
  • A hand-maintained privacy allowlist — blocked the copilot from ever touching 5 datasets with identifiable patient health data

Self-assessed as "Phase 4" of its own roadmap.

Headline capability shift

From a form-filler to an AI-native platform

  • Native Superset AI protocol (MCP) — replaced the hand-built tool loop with Superset's own first-party integration
  • Verified per-user permissions — row-level security confirmed with real accounts, not assumed
  • Self-building and self-healing — proposes reusable workflows and repairs its own broken dashboards
  • Multi-tenant by design — one dashboard can serve many districts securely, no per-tenant accounts
  • A real product surface — a published, branded dashboard homepage, not just a chat window
03

Capabilities Built in the Last Two Weeks

Foundation

Native AI protocol (MCP)

  • Reads and writes wired to Superset's own MCP service — chart/dashboard creation, updates and queries go through Superset's first-party protocol
  • Fixed two real bugs in Superset's own MCP+JWT integration — without a fix, auth would've silently collapsed to one shared account
  • Full write-path authorization — writes execute in the user's own browser session, never a service account

Security & identity

Row-level security

  • 19 of 22 datasets found to be production-backed — scoped RLS enforcement to the one dataset that's actually staging data
  • Verified with real accounts, not assumed — Wakiso analyst sees only Wakiso rows (330); Iganga analyst sees only Iganga rows (1,148); admin sees all 49 districts
  • Caught and fixed a silent RLS break — a column rename had quietly broken row-level security for every non-admin user

Creative surface

Open canvas & skills system

  • Custom-visualization "canvas" mode, open to all users — not just admins
  • "Skills": propose → review → approve → reuse — a human must approve a workflow before anyone else can use it
  • Verified per-user re-execution — a skill applied by a different RLS-scoped user returned that user's own data

Reliability

Self-healing dashboards

  • Detects charts broken by renamed or missing columns — empirical detection; every chart is actually run, not statically parsed
  • Found 3 real production-grade bugs while building it — including one hiding since an earlier session
  • Auto-repair gated to staging only — production-backed datasets are always report-only

Scale

Embedded per-tenant dashboards

  • One dashboard, many districts, zero extra accounts — per-tenant scoping travels inside a signed guest token
  • Verified end-to-end with an unauthenticated client — two guest tokens, two districts, correct row counts for each
  • A dedicated Guest role built — kept the existing locked-down Public role untouched

Portability

Reproducible dashboard packages

  • Export and re-import dashboards as a self-contained bundle — wraps Superset's own native export/import
  • Credentials always stripped — a portable export should never carry live database passwords
  • Verified with a real round trip — exported, re-imported, then pulled live chart data back from the result

Visualization

New chart types & styling

  • 6 new chart types added — box plot, funnel, histogram, treemap, waterfall, sunburst
  • Prompt-driven dashboard styling, fixed properly — root-caused to Superset's own rendering internals
  • Maps enabled — new geospatial datasets catalogued for facility and sub-county visualizations

Quality

Automated evaluation harness

  • A real test suite built and run against the copilot — 20+ scripted questions against live staging data
  • Found and fixed a genuine bug via the harness itself — a column-name mismatch silently returned the wrong counts
  • Honest scorekeeping — 60% pass rate before the fix; a full re-run after fixes is a tracked next step

Engineering health

Frontend modernization

  • Migrated Superset's drag-and-drop engine off a deprecated library — react-dnd → @dnd-kit, across the dashboard editor and chart builder
  • 185 tests passing, 18 test files — verified beyond "the build compiles"
  • A real, severe bug caught before it shipped — a crash in the "Group By"/"Metrics" pill used on every Explore page

Product surface

Custom dashboard homepage & publishing

  • Dashboards now publish to a stable, shareable homepage — not a raw Superset iframe
  • Redesigned this week — LifeData's own brand, a dashboard creator, personalized home
  • Drag-and-drop layout editing, light/dark themes — owners can resize and reorder their own published dashboards

Chat experience

Multimodal copilot upgrades

  • Screenshot paste, file uploads, voice input — images, PDFs and office files now reach the model as real context
  • Calmer, clearer UI — plain-language status messages instead of raw tool names; softer error styling
  • Publication links persist across reloads — a published dashboard's link survives a refresh or new conversation

Open items & decisions needed

What's not done, and what needs a call

  • Privacy gate on 5 PHI-bearing datasets was removed — deliberately, to be rebuilt "later, in production"; needs an owner and a timeline
  • Full evaluation suite needs a complete re-run — only a spot-check has happened since the last round of fixes
  • A second, older AI dashboard chat project is still running — needs a decision: retire it, or clarify what it's for
  • Frontend drag-and-drop migration is done but not merged — completed and tested locally, not yet in the live Superset image
  • One admin password was reset during testing — disclosed immediately, still needs rotating
